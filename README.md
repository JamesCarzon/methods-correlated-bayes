# methods-correlated-bayes

This repository contains content for 36-735/736: Methods for Correlated Data and 
Bayesian Statistics I & II.

## Tools

Optimal convenience for solving homeworks in this course may involve using a 
number of tools and pieces of software, e.g.:
- R
    - `lme4`
    - `nlme`
- Python
    - `torch`
    - `jax`
- STAN
Note that there are libraries for exposing STAN command-line functions through
R- or Python-interpretable wrappers. See the [STAN website](https://mc-stan.org/users/interfaces/) 
for more information.

In addition, we recommend using a system for interpreting both R and Python with 
Markdown for typesetting documents for the course, e.g.
- RMarkdown
- Jupyter Notebooks
- [Quarto](https://quarto.org/)
Extensions for these systems are readily available for free in Microsoft VSCode.
